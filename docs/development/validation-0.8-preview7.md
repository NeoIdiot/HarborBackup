# 设置页整理（0.8.0-preview.7）

日期：2026-11-03。

## 界面调整

- 帮助从滚动内容移入主窗口固定底栏，顺序为“保存备份设置 / 重新加载 / 帮助”；英文显示 Help。
- 历史版本、冲突、元信息目录和两项本机保留策略移除重复账户管理按钮，当前值占用剩余行宽。
- 设置顶部保留唯一“管理账户与云端仓库”入口，继续管理登录、仓库和保留策略。
- 移除配置目录、日志目录两行。运行记录页保留原有“打开日志目录”入口；高级配置保留项目配置和系统配置文件入口。

## 配置入口检查

| 功能 | 界面入口 |
| --- | --- |
| 账户、仓库、云端布局、本机保留策略 | 设置顶部统一管理 |
| 语言、登录启动、备份间隔、启动延迟、运行时限、完整核查、项目错误处理 | 原有设置控件 |
| 哈希缓存开关 | 补齐复选框，对应 sync.hash.useMetadataCache |
| 日志、运行记录保留时间 | 补齐天数输入，对应 logging.retentionDays / history.retentionDays |
| 项目路径、排除规则 | 备份项目编辑器；高级项目配置 |
| 已有保护副本保留策略应用、可重建缓存占用与清理 | 保留操作按钮 |
| 安全固定策略：SHA-256、覆盖前保护、不传播删除 | 不提供关闭按钮，说明留在帮助 |

新增控件复用既有配置字段、默认值和验证范围，不改变备份规则。
所有解释放入中英文帮助；日志和运行记录保留时间不作用于备份文件、保护副本或恢复事务。
