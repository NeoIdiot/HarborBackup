# 0.9.0-preview.19 项目改名与列表移除

日期：2026-11-11。

## 原因与修复

原项目列表只按 destination 文字合并本机配置和云端登记。编辑目标路径后，原 project.json 仍保留在按旧路径计算的管理元数据目录，因此出现新的本机行和旧的仅云端行。仅云端行又被禁止使用整个“更多操作”菜单，无法移除。

- 保留本机项目 ID；目录编辑仍只保存配置。列表排除同账户中已被替换的旧映射路径，旧恢复映射和共享记录保持不变。
- 云端目录清单按 folderId 查询当前父目录链，显示改名/移动后的路径，并按 folderId 合并历史登记。读取不改写共享登记，不下载业务正文；仅忽略确认的 404，403 等错误继续显示诊断。
- 本机项目行携带配置中的目录 ID，合并及加入/取回入口识别相同目录，避免按旧名称重复加入。
- “更多操作 → 移除项目…”对仅云端行可用；核查、上传等本地操作仍要求本机映射。
- 移除保存 `projects.json.dismissedCloudProjects`，按云盘、仓库、管理根和目录 ID 限定本机列表偏好。刷新、重启、失效授权和首次无配置均可保存，不删除云端文件或任何恢复/保护材料。重新通过添加项目选择该目录后，本机映射优先显示。
- 列表与云端项目选择器使用相同过滤；云端数量按可显示项目计数。用户指南明确移除仅影响本机。
