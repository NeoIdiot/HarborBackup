# 0.9.0-preview.2 验证记录

日期：2026-11-04（Asia/Shanghai）。

## 功能

- 普通备份与取回均跳过缺少可信元信息的云端文件。
- “更多操作 → 取回并建立基线”单独预览未知元信息或无共同基线的不同文件。
- 取回预览支持逐项勾选，包含写入目录、新增/更新数量、预计下载量和待处理数量。
- 确认依据绑定本机目录、设备、账户/管理仓库/项目映射、共同基线和双方内容版本。
- 执行只处理选中清单；新增条目不纳入，变化条目跳过。所选本地文件重新哈希，避免相同大小/时间掩盖预览后编辑。
- “取回云端项目…”选择云端项目和本机目录，确认预览后保存映射并取回。取消预览不保存新项目；已有映射复用本机目录。
- “加入云端项目”保留为只保存映射的操作。
