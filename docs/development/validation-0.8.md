## 尚需外部环境的验收

需要维护者注册的公共桌面应用 Client ID 和用户交互授权，才能验证真实个人/组织 OneDrive 的授权、失效重连、分片恢复、云端复制完成监测和实际摘要返回。还需两台实体设备交接及大型项目耗时、长期空闲/峰值内存测试。

当前没有提供 Client ID，未访问真实账户或上传生产数据。这些外部验收未完成前，不将此包标记为正式稳定版本。使用流程见 ../user-guide/onedrive-account.zh-CN.md，协议和目录设计见 ../architecture/onedrive-account-transport.md。
