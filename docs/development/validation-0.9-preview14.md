# 本机目录切换与配置解耦（0.9.0-preview.14）

## 行为

- 保存项目只更新配置，不扫描、迁移、上传或拉取业务文件，不要求源目录已存在或账户当前可用。保留结构、路径重叠校验、运行互斥和并发保存签名检查。
- 切换目录保留项目 ID 和云端目标，生成本机 mappingVersion。切回旧目录同样是新映射，不复用旧基线或摘要缓存。历史、旧状态和冲突材料保留。
- 项目显示“待首次上传或拉取”；首次明确操作完整成功后写入状态确认，继续原自动备份策略。只读预览、部分处理、失败、取消及恢复旧事务不激活新映射。
- 上传与拉取预览提供逐文件选择，覆盖前保护相反一端的内容。拉取自动处理建立基线，不再要求进入单独的“取回并建立基线”菜单。
- 配置保存保留旧映射元信息；新 v5 事务包含原映射快照，旧 v4 事务可以通过当前或保留的映射恢复。恢复校验身份、路径和格式，写入原目录。未完成事务不阻止配置保存或只读预览，只跳过路径重叠的文件，同项目其他文件可继续；上传/拉取不隐式恢复旧事务。
- CLI 提供 `preview --prepare-upload`、`backup|pull --selection <报告绝对路径>` 和 `backup --automatic`，执行使用与桌面相同的用例。

## 验证范围

使用合成数据、合成云盘及独立临时目录。覆盖配置离线保存、缺失目录、旧事务保留、切回旧路径的新映射、自动任务跳过与恢复、两种方向的受保护覆盖、上传确认后同大小同时间戳改写、部分选择、损坏恢复映射、v4/v5 原目录恢复、其他项目继续执行，以及未知云端内容保护记录不伪造 SHA-256。

桌面测试覆盖直接保存源目录切换、无隐式预览或映射确认弹窗，以及中英文上传选择清单。
