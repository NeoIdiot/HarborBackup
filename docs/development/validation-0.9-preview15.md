## 修复内容

- 旧格式普通目录事务按原映射和文件隔离，不再因发现版本 2/3 而在项目循环之前抛出全局异常。其他设备的记录不参与本机恢复。
- 版本 2 的旧暂存上传可显式核验并安全结束：必要时恢复已移走的云端原文件，保留旧事务、归档、暂存和本地回滚材料。之后由用户重新上传或拉取。不会把旧字段直接套入新事务格式，也不推断共同基线。
- 版本 3 尚无已核实的回放规范，只允许定位受影响文件，不自动恢复。版本 1、未知/损坏格式和缺少原映射的记录仍保留并停止无法证明安全的写入，但会生成运行记录和具体诊断，而非仅展示“请换旧版”。
- “查看选中详情”和双击运行记录打开独立详情窗口。关闭保留原页面、筛选和选中行。“待处理问题”只展示最近结果的待处理条目，历史报告不再混入。
- 详情支持搜索、仅看待处理和完整可复制错误文本；预览及问题页也可查看完整条目。

## 场景覆盖

- 旧上传 Prepared / Staged / Archived / Published，归档响应丢失、恢复响应丢失及重试；重新预览并上传成功。
- 暂存内容变动、云端并发修改、父目录错误、越界路径：拒绝恢复且原记录逐字节不变。
- 旧拉取替换前/后：安全结束不改写任何一侧业务内容，本地回滚保留。
- 切换本地目录后使用原映射恢复；新目录不创建，新映射不误标为就绪。
- 旧事务与同项目正常文件、其他项目共存；其他设备旧记录不阻断本机。
- 损坏 JSON、未知版本、丢失原映射：失败结果写入历史和最近运行状态，禁止业务写入。
- 中英文紧凑/标准详情布局、完整长文本、筛选空结果、损坏历史、弹窗关闭后页面及选中项保留。
- 原有配置纯保存、三方比较、覆盖保护、上传/拉取、失败恢复、并发及安装布局测试继续执行。
