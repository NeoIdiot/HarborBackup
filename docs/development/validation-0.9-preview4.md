# 0.9.0-preview.4 草稿预览响应修复

日期：2026-11-04（Asia/Shanghai）。

## 原因

代码检查确认预览已有 Task.Run 后台执行，并非直接在 UI 线程同步扫描。问题在交互与取消链：
- ProjectEditorDialog 将整排操作禁用，取消按钮不可用；busy 时阻止关闭。
- 配置验证后状态停留在“配置有效；尚未保存”，实际云端目录/元信息读取及本地扫描没有进度传到该窗口。
- ConfigurationPresenter 经 ExclusiveAsync 调用预览时丢弃了协调器取消令牌，预览使用默认令牌。
- 另发现取回预览绑定勾选项时，每次设置单行值都重新遍历所有行计数，造成平方级初始化工作。

这些缺陷可以解释用户截图中的不可操作状态，但本轮没有读取用户进程转储或真实云端请求轨迹，不能据此断言该次等待具体卡在哪个服务请求。

## 修复

- 草稿预览提供停止按钮，关闭窗口先请求取消，后台退出后关闭；停止后保留原草稿并允许重试。
- 取消令牌连接桌面协调器、配置编辑器、云端预览、目录/元信息枚举和本地哈希。
- 显示当前阶段、处理数量、哈希字节数及耗时。工作线程只更新最新进度，UI 每 250ms 读取一次，避免逐文件向消息队列投递。
- 预览遵守现有单轮运行时限，超时显示专用提示；无需新配置项。
- 取回列表初始化期间暂停全表统计，批量赋值完成后只统计一次。
- 引入小型 IConfigurationPresenter 接口供界面隔离测试，不修改项目配置格式或备份决策规则。

新增专项测试：
- 模拟慢扫描和慢云端等待，UI 心跳继续、停止按钮可用。

- 回归覆盖：被排除本地内容不哈希、云端目录不递归、不进入预览或上传、普通取回仍遵守排除规则。
