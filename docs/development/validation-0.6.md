# 0.6.0 多设备文件元信息验证

日期：2026-11-01。设计见 [共享元信息协议](../architecture/shared-metadata.md)。本次不修改用户正式安装、真实备份目录或原 PowerShell 计划任务。

## 实现范围

- 默认在 OneDrive/AutoBackup/HarborBackup/metadata 下按目标相对目录、设备身份分别发布 JSON。每台设备只写自己的记录，源绝对路径和本机事务不共享。
- 共同基线驱动单边/双方变化判断；已有基线的单边修改不再受设备时钟先后影响。双方变化保护两份内容，支持用户逐文件选择并在提交前再次核验。
- 元信息先到、内容未到时暂缓写入；损坏或同步冲突记录保留并提示。发布失败保留本机 outbox，下次运行重试。元信息故障不阻止未完成文件事务恢复。
- 扫描观察先持久化，完成结果按项目批量发布；共享读取按相对路径建立索引。其他设备目标摘要不一致时强制核查本机文件，防止大小和时间未变化的缓存掩盖已到达内容。
- 增加设备文件状态窗口、显式冲突选择、共享目录设置及只读 devices CLI；中英文界面和帮助同步更新。

## 未验证边界

双设备由隔离目录与显式复制元信息/内容模拟，没有使用两台真实电脑或真实 OneDrive 网络。未验证长期离线、真实云端同步冲突、所有网络时序及跨设备同时写入。独立 JSON 不提供分布式锁或强一致事务；历史已观察摘要也不是版本因果图。

首次没有共同基线仍保留原有较新版本优先且覆盖前保护的规则。用户新接入一台设备应先等 OneDrive 同步并预览/取回。元信息不携带文件内容；保护副本默认留在各设备本机，不能仅凭 JSON 恢复文件。

正式包与验证包使用同一发布载荷；本轮不替换用户正式安装，不重复验证正式卸载注册和开始菜单快捷方式。
