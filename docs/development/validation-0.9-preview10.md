# 0.9.0-preview.10：第二台设备的云端项目列表

日期：2026-11-04。

## 行为

- “备份项目”直接合并本机配置与当前管理目录 metadata/projects 中的项目登记；匹配目标相对路径时忽略大小写、统一分隔符。不依赖本机已存在项目，不将云端行自动加入配置或调度。
- 本机状态区分已关联的目录存在、目录缺失、路径不是目录、不可访问，以及未关联本机目录。未关联不是“在整台电脑上不存在”；不扫描其他目录。目录存在也不代表内容最新。
- 选中云端行后“取回云端项目…”直接使用该项目，让用户选择本机保存目录、预览并明确确认取回。已有本机映射时使用该映射。未关联行不能执行备份选中、普通取回更新、编辑、移除等本机配置操作。
- 原有加入/取回按钮错误依赖本机项目数量，导致新设备无法创建第一个项目。现改为依据账户绑定、授权与运行互斥判定。
- 首次打开项目页异步读取云端项目，可手动刷新、取消；离开页面取消加载，60 秒超时。使用同一运行互斥，缓存写入不会与备份并发。周期状态刷新不重复调用云端目录。
- 刷新失败保留已有行并显示错误；账户/管理目录变化清除旧列表。元数据登记用于发现项目，不下载业务文件正文。取回仍由已有元信息比较与确认规则决定。
- 新增文案同时提供简体中文和英文；未新增依赖、后台服务、配置格式或备份规则。

## 验证

桌面全量回归 53 项通过（原有 41 项，新增 12 项）。新增用例覆盖新设备无配置/空项目、账户未绑定/需重新授权、互斥忙碌、云端和本地合并、目录存在/缺失/文件占位、按选中行限制动作、周期刷新不触网、取消与页面导航、加载失败保留行、账户变化清理旧列表，以及仅查看项目不保存配置。

界面截图使用合成项目和临时配置，输出 artifacts/ui-preview10。生产账户、备份内容和安装目录未修改；真实两台设备交接尚未进行。本轮不重复此前运行时与安装器布局的隔离安装验证，当前正式托盘仍在运行。
