# 侧栏图标裁切修复（0.8.0-preview.3）

日期：2026-11-02。

原因：导航按钮的图标绘制区域只有 22 个逻辑像素，使用点字号并保留 TextRenderer 的默认字形留白。部分宽图标的有效空间不足，造成左侧笔画裁切。

修复：图标使用独立的 32 像素栏，字号按控件 DPI 换算为像素，只缩放一次；去除文字默认留白。文字从 52 像素处开始，图标栏和文字之间保留间距。概览、项目、历史、问题、设置、退出统一使用同一绘制方法。

验证：
- Desktop 工程 25 项通过。TRX：artifacts/test-results/navigation-fix/*_2026-11-02_19_15_45.trx。
- 六个图标在 96、120、144、192、240 DPI 下与不受窄栏限制的参考图逐一比较：着色像素数量和边界尺寸相同，无裁切，文字区域不重叠。
- 检查中英文完整窗口截图，图标、选中标记和文字排列正常。图片：artifacts/ui-navigation-fix。
- 测试截图合成时统一位图 DPI 后，五档图标测试再次通过。
- 多档位验证是绘制测试，不代替物理显示器跨屏测试；实际窗口截图为当前测试环境 DPI。
- 本次未更改备份、授权、配置和安装逻辑，未重新运行 Core/云端事务全套测试或安装升级验收。
