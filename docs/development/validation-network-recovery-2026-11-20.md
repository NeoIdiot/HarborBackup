## 源码与行为

完整测试在未提交开发工作区执行。基准提交为 `7aec0b7e5c1bbeebdb962adfbe158597e4113991`，tree 为 `97c422b8b7ee46ed2ca704fb7f235693691e9eb9`，报告明确记录 `clean=false`。该提交号不代表本轮未提交修改的完整源码快照。

- 报告区分等待自动重试、需要确认版本、需要修复和主动停止。网络等待保留原因，不触发人工故障通知；混合问题仍显示真实冲突或修复项。
- 原授权、项目 ID、设备、账户、物理映射、任务范围、逐文件回执和预算持久保存在 state。自动续行核验原意图，不取得手动采用当前本地版本的权限；旧记录缺少授权时保持人工恢复。
- 首次明确上传或拉取可续原范围，排除未选择和后来新增的文件，完整完成条件不变。首次拉取使用实际下载校验后的哈希记录完成状态。
- 上传成功但回执丢失时核验现场，元数据或设备状态尚未提交时补齐收尾，避免再次传输已核验正文。竞争版本、损坏记录和映射变化保持保护。
- 离线、暂停或忙碌不消费到期触发。联网后约两秒防抖；暂时故障采用带抖动的退避，服务端 Retry-After 优先。长自动冷却释放运行锁；启动异常不会把候选卡在正在尝试状态。
- 快速重试保留原预算，源变化后安全关闭旧意图再开始新意图时追加其完整预留；重启后累计消费保持。新正常周期才可开始新预算。
- 独立等待任务可排队；嵌套目录的已完成只读行不被兄弟文件阻断。摘要只省略另一个有可信任务、事务 ID 和最新回执证明的独立网络等待，旧记录和人工问题继续报告。

当前格式及规则见[账户传输设计](../architecture/onedrive-account-transport.md#network-interrupted-task-continuation)，用户行为说明已同步中英文指南。

## 验证边界

网络中断、丢失回执和服务冷却使用合成云盘、受控 HTTP handler、假时钟及独立临时目录验证。未进行真实账户断网恢复、大文件吞吐、实体双机、断电或安装版验收。进程中断探针只终止本轮创建的测试子进程。

CLI `backup --automatic` 在下一次调用时使用相同恢复规则；退出后不驻留监听网络。桌面自动唤醒要求后台程序运行，暂停和主动停止不会因联网事件自动恢复。
