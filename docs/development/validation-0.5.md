## 安装现有电脑

0.4 的程序文件采用平铺布局。先从 Windows 已安装的应用正常卸载旧版本，再安装 0.5；新安装器检测到旧平铺入口会停止并提示。0.5 不导入旧配置，首次使用通过设置重新选择目录和添加项目。今后 0.5 布局内的升级与卸载保留 data。
