# 云端设置保存与窗口修复（0.8.0-preview.5）

日期：2026-11-03。

## 原因与修改

- 账户已登录但仓库未绑定被统一显示成“未设置”；保留策略单独保存又显示“设置已保存”。现在区分未连接、待选择仓库、仓库位置和需要重新授权。
- 仓库绑定和本机保留策略统一由“应用云端存储设置”提交。窗口区分创建新仓库与使用已有文件夹，显示目标路径；已有仓库读取共享布局，禁止界面误改布局。
- 只有远端仓库身份校验通过且本机配置原子写入后显示成功。普通非空目录仍被拒绝。错误显示明确摘要，详情单独查看；失败保留用户选择。
- 账户窗口改为内容滚动、底栏固定。底栏按钮禁止换行裁切，状态文字按可用宽度换行。重新打开自动异步浏览已保存仓库；刷新保留名称和选择。首次只读加载不与定时刷新争抢用户操作状态。
- 普通设置解析抽取到 BackupSettingsReader，与执行前的账户就绪检查分离。未登录、未绑定或源目录暂不可用时仍可保存普通设置；运行仍要求账户与仓库就绪。
- 添加可替换的账户操作小接口用于离线界面测试。仓库应用与 CLI 绑定共用执行流程，在后台线程持有进程互斥，完成后统一保存。
- 断开连接保留仓库信息并记录 RequiresAuthorization，后台执行拒绝运行，重新连接成功才清除该状态。兼容缺少该可选字段的现有配置。
