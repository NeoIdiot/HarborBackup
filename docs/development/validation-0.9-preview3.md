# 0.9.0-preview.3 UI 统一与验证

日期：2026-11-04（Asia/Shanghai）。

## 检查与处理

| 部分 | 原差异 | 当前处理 |
| --- | --- | --- |
| 项目“更多操作” | 系统默认灰色图标栏、矩形边框、系统阴影 | 与托盘共用 AppMenu；项目菜单不预留勾选栏，托盘保留暂停勾选栏 |
| 项目源/目标/实际路径 | 原生直角文本框，实际路径灰色背景 | 使用 InputFrame，统一浅色背景、四周细边框、小圆角和焦点色 |
| 排除规则 | 多行原生边框 | ContentFrame 保留原生编辑、滚动与输入法，统一边框 |
| 云端目录/账户目录/项目列表/冲突列表 | 默认列表边框、紧密行距和系统蓝色选择 | AppListBox 与 ContentFrame，按字体和 DPI 计算行高，统一选中色 |
| 取回预览/项目编辑/子目录/冲突/帮助底部操作 | 部分靠左，部分靠右，项目选择按钮横跨窗口 | 共用 DialogActions，整体右对齐，保留原有顺序及键盘 Tab 顺序，窄窗口可换行 |
| 云端项目选择 | 临时拼装的 Form | 独立 CloudProjectDialog，共用窗口、输入与按钮样式，支持确认/取消 |
| 帮助 | 正文独立字号、内容无统一边框 | 正文继承窗口字号并接入内容边框 |

主窗口的页面工具栏保持靠左，窗口级操作保持右侧；设置与账户已有固定右侧操作区继续使用其布局。
系统 MessageBox、文件夹选择器和原生下拉/日历保持 Windows 交互。未引入第三方 UI 框架、字体包或新的运行时依赖。

## 共用约定

- 单行输入使用 AppStyle.Input → InputFrame；多行编辑、富文本和列表使用 ContentFrame。
- 应用弹出菜单使用 AppMenu，不直接实例化 ContextMenuStrip。关闭系统阴影和图标灰边。
- 列表使用 AppListBox，保留 ListBox 的选择、数据绑定、滚动和辅助功能行为。
- 表单沿用 AppStyle.Configure，底部独立按钮区优先使用 AppStyle.DialogActions。
- 圆角：输入 4、卡片 6、菜单 8 个逻辑像素。边框与选中色来自 AppStyle；高对比度使用系统颜色。

## 验证范围

全部操作在隔离配置与合成数据中执行，无真实账户网络请求、正式配置写入或业务备份。
桌面测试包括中英文、最小窗口、输入文字高度、项目选择确认、取回勾选、账户草稿与状态保存、托盘菜单状态和菜单圆角。
菜单额外模拟 150% / 175% / 200% 字号放大；账户窗口已有 100% / 150% / 200% 缩放回归。模拟缩放不等于物理多显示器 DPI 切换验收。
