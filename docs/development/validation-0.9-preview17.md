## 已调整的边界

| 原有耦合 | 调整后 |
| --- | --- |
| 文件已完成但设备状态上报失败，整项失败且新映射仍未就绪 | 文件结果与就绪状态先落定；上报单独提示待重试，不停止无关项目 |

| 只读云端列表加载占用操作队列，禁用本地编辑 | 独立读取和取消，列表加载时可编辑并保存本地配置 |

## 保留的约束

配置提交的互斥和并发签名检查、真实账户/仓库切换核验、覆盖保护、事务恢复身份验证、源/目标写入方向、提交共同基线前的内容核验继续保留。无法确认作用范围的恢复材料不授权写入。不自动重写损坏的调度或最近运行记录。

## 场景测试

- 设备状态响应丢失：两个项目的文件均完成、就绪不撤销；即使 ContinueOnError=false，非致命上报提示不终止后续项目；下次自动运行重试 outbox，文件不重复写入。
- 损坏 JSON、未知格式和越界恢复路径：已知映射只阻断该范围；云端 ID 或本地路径重叠仍阻断；未知归属禁止写入。
- 事务目录与内嵌绑定互相矛盾（内嵌快照正常或损坏两种情况）：不采信单一目录范围，保守禁止写入并逐字节保留原记录。
- 损坏 readiness：预览和配置可用，自动备份等待手动确认；预览不改 marker，手动成功后建立新的就绪证明。
- 损坏 scheduler/last-run：项目仍显示、系统配置保存成功、原记录不变、重复刷新保持行对象；调度状态损坏时暂停自动运行。
- 待重新授权、离线及待恢复事务同时存在时保存原仓库的本地保留偏好；不打开传输；实际切换位置仍被阻止。
- 账户窗口离线打开仍能保留原仓库选择并保存偏好；云端目录加载无限等待时，本地配置仍能保存，导航仍可取消列表读取。
