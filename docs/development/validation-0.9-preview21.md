# 0.9.0-preview.21：安装时自动检查和重建

日期：2026-11-11。

## 改动

用户无需手动执行重建命令。安装器在复制程序后、启动应用前，调用已安装的格式检查用例：

- 首次安装自动生成空的新格式配置。
- 旧项目格式、非法项目 ID、旧账户/当前设备运行状态格式、缺失或损坏的必要配置，自动将原 data 整体留存为同级 data-retained-*，再生成空配置；不迁移旧项目。
- 当前格式保留原文件、项目 ID、凭据及恢复材料；重复安装不重置、不额外创建留存目录。
- 不访问源目录或云端，不以源目录暂时缺失或网络离线作为重建条件。
- 读取失败、配置文件占用等 I/O 错误中止安装，不将不可读数据当作旧格式强制重建。业务正文不参与检查或重建。

安装器在整个检查期间持有维护标记，以本次安装的随机临时目录摘要生成独立租约标记。内部 CLI 入口只接受活动租约，核验维护和无运行进程标记后，在启动互斥与运行锁内检查/重建。程序启动前才释放维护；检查失败不执行启动项。手动 initialize 命令保留为维修工具，不是安装步骤。
