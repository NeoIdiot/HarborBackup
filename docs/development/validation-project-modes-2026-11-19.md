## 修改范围

- 项目编辑使用“仅上传 / 双向备份 / 仅下载”下拉框，默认仅上传。配置写入 `automaticBackupMode`，继续读取旧布尔配置；非法模式拒绝读取，切换策略保留映射、基线和就绪状态。
- 桌面、托盘“立即运行”、定时执行和 CLI 自动执行共用项目策略、暂停及预算。显式上传和下载继续保留各自方向；未初始化或本地根丢失时不会静默启动自动写入。
- 仅下载不修改云端业务文件，仍允许管理元数据和覆盖前保护材料写入管理目录；不传播删除，双方修改保留冲突并等待明确选择。
- 项目列表移除“实际目标”，保护状态改为单行且固定行高，详细记录保留在悬停提示和项目状态窗口。编辑窗口仅保留相对 OneDrive 根目录的项目云端目录，未改变项目实际映射。
- 同步中英文资源、用户指南、架构和配置示例；固定上传方向的预览入口明确为“预览上传”。
