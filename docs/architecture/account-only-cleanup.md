# 账户模式代码清理

日期：2026-11-02。适用版本：0.8.0-preview.2。

账户直连为唯一备份执行链。删除旧同步目录模式的文件会话、归档器、恢复记录、基线适配、共享快照、占位文件保留/释放空间、存储位置配置和重复冲突窗口。Core 中只有旧适配器使用的 BackupService、PreviewService 与接口同步移除；保留三方冲突决策、文件校验模型、调度和报告。

CLI/桌面不再接受 --onedrive-root。storage-settings.json 不再决定执行方式；旧文件不删除也不自动迁移。没有已绑定账户时不能执行备份。若旧版本有未完成事务，应使用对应旧版本先完成恢复，再使用账户模式。

桌面设置只显示云端仓库和账户版保护策略。旧占位文件重试、旧位置列表和无效缓存开关已删除。中英文帮助仅说明现有功能，安装包仅携带账户模式使用说明；历史文档继续保存在 Git。

恢复事务、基线、源文件、历史保护和真实账户数据不在此清理范围。私有 .NET Runtime 不裁剪、不删程序集，保留双语界面、CLI 和 WinForms 托盘。MSAL 与凭据保护依赖仍为账户功能所必需。

测试与发布：旧模式专属测试随实现移除，云端传输测试移入 Integration 工程。通用配置、路径、调度、状态、UI、Graph 协议和冲突恢复测试继续运行。新增旧配置不能启用目录模式、删除缓存保留事务和旧参数拒绝测试。安装验收采用合成账户配置，只验证本机生命周期与授权缺失行为；真实云端验收仍需用户提供 Client ID 并授权。
