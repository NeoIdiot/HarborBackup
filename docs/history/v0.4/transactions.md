# 文件事务与恢复设计

## 目标与限制

提供单文件写入的可追踪恢复；不宣称文件、多个 JSON 与 OneDrive 构成一个原子事务。当前实现新写入 schemaVersion=2，兼容恢复旧 v1；协议选择见 [ADR-0004](decisions/0004-transaction-v2.md)。下面逻辑阶段中 Verified/Committed 为核验和提交检查点，磁盘阶段保持 Prepared/Protected/Staged/Replaced，恢复不依赖阶段单独决定动作。

## 逻辑状态机

| 阶段 | 成立条件 | 恢复原则 |
| --- | --- | --- |
| Prepared | 已记录意图、映射、方向和预期版本 | 校验记录和现场，不假定已经复制 |
| Protected | 需要保护的旧版已保存且核验 | 保留保护内容，检查下一步前置条件 |
| Staged | 同卷暂存新内容并核验 | 重新观察源和目标，变化则延期 |
| Replaced | 已尝试提交目标替换 | 读取实际内容判定结果，不盲重做 |
| Verified | 新目标及必要前提核验通过 | 可以提交基线与文件状态 |
| Committed | 文件状态持久化成功 | 清理不再引用的临时材料，更新展示摘要 |

旧阶段包括 Prepared、Archived、Staged、Replaced，只在 v1 读取分支解释。新阶段不写进旧 schema。完成时先提交 files.json，再清理核验过的 rollback 和事务记录；若中途停止，重复恢复根据当前内容补齐。

## 记录内容

v2 记录包含版本、事务 ID、设备/任务关联、模式、相对路径、源/目标根绑定、两端预期 FileVersion、动作、保护分类/侧、暂存/回退名称、阶段与时间。归档路径由已验证配置和记录的内容版本确定，不接受任意替换路径。v1 的 archivePath 必须位于配置的普通归档或冲突根内并通过摘要核验。

从 JSON 读出的路径必须重新验证，不能直接作为任意绝对路径执行。相对路径不得逃出根，禁止链接/联接越界；映射改变、设备不匹配或记录未知时保留原记录并停止受影响恢复。

## 提交流程

1. 取得运行锁，验证当前配置与事务边界，观察两端的真实版本。
2. 先持久化事务意图，再进行不可逆业务写入。
3. 对被替换的不同内容建立并核验归档；失败则不覆盖。
4. 在最终写入位置同卷暂存新内容，关闭/刷新写入流并核验哈希。
5. 再次验证源和目标。任何已观察到的外部变化均导致延期或重新决策。
6. File.Replace 将实际旧文件保留到目标同目录 rollback；新建用拒绝覆盖的 File.Move。持有源读句柄阻止普通写入/删除。实际旧版与预期不一致时保留 rollback 和事务并报告延期。
7. 验证落盘内容；提交 files.json 后再结束事务，status.json 作为展示摘要更新。
8. 只有确认事务不再需要的材料才清理；维护失败单独记录。

Pull 目标可能与工具目录不同卷；不能把所有暂存和替换备份都放在工作区。替换涉及的本地备份需符合 Windows API 同卷约束，长期归档可在单独核验后转移到归档存储。

## 并发变化与持久性

检查与替换之间存在竞争窗口；单纯重复 GetFileInfo/哈希无法消除。当前使用实际被替换版本保护，已测试目标在最后检查后改成第三个版本仍被保留，不能以本程序互斥推断外部编辑器也被锁住。任意链接替换竞争、硬链接/特殊文件系统以及硬件断电仍需专用验收。

如不能保证保护被替换版本，延期该文件，不使用删除/覆盖兜底。文件替换的错误可能留下部分阶段结果，恢复必须检查实际路径内容。

暂存与事务数据刷新后再推进逻辑阶段，但不承诺任何硬件断电下的绝对持久性。第一版重点验证进程中断、I/O 错误和可观测的外部修改。

## 恢复决策

- 目标已是预期新内容而事务仍在旧阶段：核验其余条件后补交状态。
- 目标仍为预期旧内容、暂存完整：不重放覆盖，失效旧观察。若原读取端已不再保存该内容，先将暂存存入 conflicts；再清理可确认暂存，交给下一轮重新决策。
- 目标为未知第三个版本：保留所有证据，标记待处理。
- 归档缺失/损坏、暂存不完整、记录损坏：不猜测，不删除证据。
- files.json 已提交而事务未清理：识别已完成事实并幂等结束。
- 配置映射改变：按旧绑定识别并报告，不将旧记录套到新目标。

测试必须在每个副作用与事务落盘前后注入中断，并重复恢复至少两次，验证 INV-01 至 INV-12。清理不能通过扫描所有 *.tmp 后批量删除实现。

当前已覆盖九个提交检查点与归档/暂存异常；真实磁盘耗尽、强制杀进程和断电试验尚未完成，不能把注入异常等同这些场景已验收。
