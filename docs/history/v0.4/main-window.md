# 主窗口使用说明

HarborBackup 提供主窗口与托盘两个界面，共享运行器和状态。0.3 重设计采用紧凑图标侧栏、轻量选中态、分组设置卡片、首次使用指引和统一船锚标识；使用 WinForms 原生控件与少量自绘，没有引入 WebView 或额外 UI 框架。参考来源、设计规范和验证方法见 [界面重设计](ui-redesign.md)。

## 启动与首次配置

直接运行发布目录中的 HarborBackup.Tray.exe 打开主窗口。使用 --background 则仅进入托盘，登录启动注册会自动带上该参数。程序不创建黑色控制台。

安装版未指定路径时，项目配置和系统配置位于 `%LOCALAPPDATA%\HarborBackup\workspace`；无 installed-mode.json 的开发/便携目录默认使用 EXE 同目录。不会搜索父目录。初次缺少配置时，进入“设置”检查 OneDrive 根目录，再到“备份项目”添加项目。保存时可以初始化缺失的配置文件；加载草稿本身不创建文件。保存目录必须可写。详见 [安装说明](installation.md)。

OneDrive 根的优先级为：启动参数 --onedrive-root、本机保存的目录偏好、当前进程 OneDrive 环境变量。启动参数明确指定目录时，设置页不覆盖该参数。

CLI 不读取桌面 UI 偏好；从 CLI 操作同一映射时，使用 --onedrive-root 明确指定相同的根目录。

隔离环境示例：

```powershell
& .\src\HarborBackup.Tray\bin\Release\net10.0-windows\HarborBackup.Tray.exe `
  --config 'C:\HarborBackup-Demo\config\bakup-config.json' `
  --system-config 'C:\HarborBackup-Demo\config\system-config.json' `
  --onedrive-root 'C:\HarborBackup-Demo\cloud'
```

源目录和模拟云根需要提前存在。开发验收只使用隔离路径；正式切换仍遵守 [部署说明](deployment.md)。

## 页面与操作

| 页面 | 功能 |
| --- | --- |
| 概览 | 当前状态、上次结束、下次自动运行、项目摘要、立即备份 |
| 备份项目 | 添加、编辑、移除、全局排除、指定项目备份、预览、取回、完整核查 |
| 运行记录 | 最近 100 份明细，按项目、结果、起始日期筛选，查看文件动作 |
| 待处理问题 | 默认显示当前问题，可切换全部动作；搜索、事务恢复、打开冲突/归档目录 |
| 设置 | 语言、帮助、周期、启动延迟、运行时限、缓存与核查周期、继续处理其他项目、本机目录、登录启动 |

运行记录的文件动作与问题共用详情表格；单次显示前 1,000 条匹配项，可以继续筛选。单份明细超过 8 MiB 时提示通过日志目录查看，避免在界面中载入过大记录。损坏日志单独标记，不清除其他历史。

项目页“更多操作”中的“完整核查”只读；“核查并备份”会根据规则写目标，移除项目也位于此菜单。“取回更新”先显示选中项目的源/目标方向和计划，用户点击执行后才取回；执行时再次核验现场。“恢复未完成事务”处理恢复证据，不是历史文件还原。

所有入口使用同一个协调器，忙碌时不新增备份任务。“停止当前操作”只取消当前轮次，在安全边界生效；后续手动/自动运行仍可使用。“暂停自动备份”仅影响后续自动触发。

## 项目编辑

项目编辑保留 source、destination、项目排除与全局排除的现有规则。源支持已存在的环境变量表达式；目标填写 OneDrive 根下的相对路径，并显示解析后的实际目标。排除项每行一项，目录不支持通配符，文件通配符仅对末级文件名生效。

“检查配置”使用与运行入口相同的校验；“预览草稿”不落盘、不提交缓存或执行事务恢复；“保存配置”保存后加入后续自动备份，不立即执行备份。项目保存与系统设置分别更新各自文档，不声称两个 JSON 能构成一个原子事务。

编辑器保留未修改的字段和环境变量表达式。保存前检查两份配置的内容签名；外部编辑或同步改变配置时拒绝覆盖并保留界面草稿。用户可重新加载后比较和重做修改。

改变源/目标会改变任务映射；现有状态和保护文件保留。改变映射、排除或移除项目时，只要本机可见的任何设备存在未完成事务，就阻止保存并要求先处理恢复问题。此检查不是跨设备分布式锁。

移除项目只修改配置；移除最后一个项目后保留空列表并停止项目调度，不删除任何业务文件。C# 新增对空 folders 的支持，旧入口对空配置的行为不作为兼容承诺。

运行期间允许编辑草稿，但应用配置需等待任务结束。保存失败时不会关闭编辑对话框或丢弃输入。无法解析的 JSON 不按空配置重建，可使用设置页“打开配置”修复原件。

## 窗口与本机偏好

- 手动启动显示主窗口；登录启动只显示托盘。
- 关闭主窗口隐藏到托盘，未保存的设置草稿随窗口保留。
- 托盘双击或再次启动程序，显示并激活同一个主窗口。
- 明确退出时，提示处理未保存的设置草稿，并等待当前操作安全结束。
- 本机窗口尺寸、关闭提示、目录和语言偏好存放于 LocalAppData/HarborBackup/<配置路径摘要>/ui.json；不写进共享配置。

设置页顶部可在简体中文和 English 之间即时切换，主窗口、托盘和后续对话框同步更新，未保存草稿保留。设置行仅保留名称、输入和必要状态，不使用小字说明；操作解释集中在“帮助 / Help”。实现与兼容边界见 [语言与帮助设计](ui-language-and-help.md)。

登录启动仅在设置页明确启用/关闭时修改当前用户 Run 项，不修改旧计划任务。移动发布目录后重新登记。生产切换需确保旧周期入口停用。

## 当前边界

没有开放未实现的空间释放、普通归档/日志保留清理开关。主题当前为浅色，支持系统高对比度配色；深色主题、文件内容差异比较和历史版本恢复向导未包含在本轮。

已配置 PerMonitorV2 与 DPI 自动布局，参考 [微软桌面 SDK 配置](https://learn.microsoft.com/en-us/dotnet/core/project-sdk/msbuild-props-desktop#applicationhighdpimode)。本机布局截图和窗口测试不等同于所有显示器、缩放比例及屏幕阅读器已验收。
