# 配置、状态与路径协议

## 配置职责

| 文件 | 作用 | 管理边界 |
| --- | --- | --- |
| bakup-config.json | 项目 source/destination 与排除规则 | 保持旧拼写和语义 |
| system-config.json | 哈希、日志、复制、调度与维护策略 | 保持已支持字段和默认值 |
| state/devices/<设备ID>/control.json | 本机暂停等控制项 | 新增协议，不写入共享项目配置 |
| files.json | 文件观察、缓存与共同基线 | 只写本机目录，严格版本检查 |
| status.json | 最近运行摘要 | 展示用，不作为内容真相 |
| transactions/*.json | 操作意图和恢复证据 | 恢复用，先验证归属和路径 |
| LocalAppData/HarborBackup/<配置路径摘要>/ui.json | 本机窗口尺寸、关闭提示、OneDrive 根偏好 | schemaVersion=1，不同步到其他设备 |

control.json 只允许本设备写入。它位于同步树并不意味着共享开关；其他设备不能根据它暂停自身。已实现 schemaVersion=1、deviceId、paused、updatedAtUtc；未知设备/版本拒绝覆盖。

示例配置位于 config/examples；真实开发配置位于被忽略的 config/local，其数据目录位于 config/local/runtime，不能用 ../../runtime 逃出旧协议的配置根。示例中的环境变量由开发者在隔离环境中设置，不提供真实桌面路径。

## 三类状态不能混淆

- 哈希缓存用于减少读取；部分缓存损坏可以经显式验证流程失效。
- 共同基线用于判断双方变化；不能因“清缓存”被静默删除。
- 最近运行摘要用于展示；显示成功不能替代文件和事务核验。

现有 files.json 同时保存缓存和基线，因此损坏时保留原件并阻止相关写入，不直接整文件重建。缓存指纹变化的旧行为也须用兼容测试覆盖；若改进基线保留策略，记录为行为变化。

## 序列化规则

领域模型与 DTO 分离。读取器先检查 schema、设备、字段类型、相对路径、摘要长度、任务/文件重复键、基线一致性和时间，再转换为领域对象。

兼容测试覆盖 UTF-8 BOM、有/无 BOM、中文、UTC 时间精度、大小写、空数组、空值和未知字段。旧写入器生成带 BOM 的 UTF-8；新写入格式是否可变化，必须由双向读取测试确认，不能凭 JSON 规范推断整个旧读取链路兼容。

当前新写入保持 UTF-8 BOM，files v1 和 status v2 已由旧 PowerShell 读取器验证。status 保留未知字段、历史失败和成功时间；读到旧 status v1 时将完整旧记录放入 legacyState，不继承旧目标的成功记录。新事务 v2 的格式与回退限制见 [ADR-0004](decisions/0004-transaction-v2.md)。

版本字段不支持时拒绝写入，不猜测降级。保留原件、迁移记录和迁移前摘要；只有测试证明可逆时才声称可回退。

表单编辑使用原始 JSON 树的脱离副本，保存前校验两份配置的签名；每次只更新项目或系统文档。新建配置时先初始化不含项目的配套文档，避免半初始化状态开始业务写入。空 folders 为 C# 新支持状态。映射/排除变更检查本机可见设备事务，保留旧文件缓存与保护资料。

## 持久化与外部修改

同目录临时写入、刷新、替换；写入前比较读取时的磁盘签名/修订，检测可观察的外部修改。无变化时不重写整份缓存。

此检查不是跨设备原子比较交换。OneDrive 仍可能在本程序锁之外同步文件；发现冲突副本或新版本时保留并报告，不自动选一份覆盖。

files.json 提交失败时保留事务。status.json 更新失败不把磁盘文件回滚为旧版。日志失败与状态持久化失败分别报告。

## 路径边界

程序位置、配置根、源根、OneDrive 根、状态根、普通归档根、冲突根分别解析和验证。

- 不依赖调用者当前工作目录。
- source、destination 和日志相对路径各自沿用旧解析基准。
- 环境变量未定义或为空时失败，不猜测替代目录。
- 拒绝 `..`、保留名、歧义路径、目标别名与父子重叠。
- 检查内部数据目录与业务目录、彼此之间的危险包含关系。
- 区分允许的云占位点和会改变路径边界的链接/联接。
- 扫描阶段和执行阶段都验证边界，不能只检查字符串前缀。

## 隐私与日志

稳定关联 ID 用于诊断；日志不存文件内容、凭据或完整机器身份原文。保留旧日志命名和明细能力，新增 JSON 输出或结构化日志须明确版本。

设备摘要用于隔离写入，不是鉴权或秘密。同步到本机的其他设备状态只是已观察到的信息，必须显示观察时间，不当作远端实时状态。
