# 0.4 界面简化、语言与帮助

## 用户行为

“设置 → 界面”提供语言入口。语言列表固定显示“简体中文”“English”，切换立即生效并保存本机偏好，不需要重新启动或按“保存备份设置”。切换只更新现有控件，不重新创建窗口、不重新加载草稿；用户输入、当前页和未保存状态保留。偏好保存失败时显示错误并恢复原语言选择。

0.4.1 将帮助移至设置滚动内容的最后，独立按钮右对齐，不再重复放置标题和卡片。中文界面只显示“帮助”，英文界面只显示“Help”。

设置行保留设置名称、输入控件、单位与必要状态，去掉小字号说明。页面标题副标题、侧栏说明和重复的底部说明一并移除。帮助窗口使用正常字号、可选择复制、可滚动的离线文字，解释目录、排除规则、调度、缓存、取回、归档、暂停、退出和语言；随当前语言显示。项目编辑窗口也提供帮助入口。

备份配置仍需显式保存；本机目录、登录启动和语言单独应用。必要的取回确认、覆盖保护提示与“云端上传未验证”状态保留。

## 布局

正文和状态统一使用正常字号，设置分组标题只增加字重。设置卡片使用 AutoSize 表格行，左列填充、右列按控件测量；复合输入使用单行 AutoSize 列，移除嵌套 FlowLayoutPanel 在宽度测量阶段误判换行造成的虚高。登录启动状态与按钮同排。目录采用无内嵌边框的可复制只读输入框，由卡片边框统一包围。

主窗口顶部操作区随内容测量，保存区固定在滚动区之外；0.4.2 将“保存备份设置”“重新加载”放在窗口底栏右侧，与左侧运行状态同排，仅设置页显示。SettingsPage 继续负责操作和草稿，MainForm 仅承载底部操作栏。无反馈消息时隐藏反馈行，底部状态区按可见内容收缩。卡片统一 14/10 逻辑像素的横向/纵向内边距和 6 像素行间距；小窗口不靠缩小字体容纳内容。

## 定时读取与稳定显示

原实现每秒无条件推送界面状态，每五秒读取配置时在 loading=true/false 各推送一次。界面把 loading 当成备份忙碌，短暂显示进度条及文字，使自动高度底栏增高后又收缩，造成设置页上下跳动；保存按钮也会短暂禁用。每次读取还重建项目行，引起无变化的列表重新绑定。

0.4.2 保留读取期间的 Busy 并发保护，只在读取结束后通知界面；普通时钟滴答不再无条件通知，调度时间变化仍更新。进度区只在可取消的实际备份/预览操作期间显示。项目行内容相同时复用集合，文字未变化时不重复赋值，保留滚动、焦点和路径选择。外部修改配置、读取错误和实际执行进度仍正常显示；没有停掉定时读取来掩盖跳动。

逻辑尺寸仍以 96 DPI 定义，WinForms 负责 DPI 缩放。控件宽度随窗口调整，中文、英文分别验证；滚动区域边缘允许正常隐藏未滚动到的内容，但行内文本和按钮不能被容器裁掉。

0.4.3 调整层次：卡片圆角为 6 逻辑像素、输入框为 4；外层卡片使用 #CBD5E1 细线，输入框使用更清晰的 #94A3B8 细线，焦点时用强调色。没有模糊或额外投影。`Styling/InputFrame` 包裹实际 Windows 文本、下拉、数字和日期控件，只替换外围显示；下拉列表、日历、数字校验、键盘操作仍由原生控件完成。去掉文本/数字原生边线，并在视口中裁掉下拉/日期的原生边线，避免双重框线。

OneDrive 根目录改为同一行的标题、可复制只读路径和选择按钮。路径列随窗口伸缩，长路径可通过原生输入框横向查看和复制，不缩小字体。设置语言与数值、运行记录的筛选/结果/日期、问题筛选使用统一小圆角输入框。该调整没有更改路径值或保存规则。

0.4.4 将卡片、按钮和输入框的绘制边界向内对称放置，避免抗锯齿描边在右/下边缘被裁掉。四周使用同样的细线和约一物理像素的淡外缘，没有左上偏移或内凹斜面；输入边线减淡到 #AFB9C7。高对比度环境不绘制淡外缘。像素回归检查左、右、上、下对应位置的颜色一致。

## 设置页切换性能

0.4.3 的 InputFrame 在嵌套 AutoSize 表格的每次测量中访问原生控件首选尺寸，布局回调又重新设置子控件位置；页面显示触发整棵控件树的可见性通知，重复触发这些测量，阻塞 UI 线程。测试中已有草稿的重复切换也需约 3.5 秒，说明不只是初次读文件的问题。

0.4.4 关闭输入框外围 Panel 的 AutoSize，高度仅在字体、DPI 和句柄变化时测量并缓存；宽高改变时直接排列内部编辑器，固定左上锚点，避免尺寸反馈。切页期间暂挂容器布局，统一设置可见性后再提交外层布局。配置加载仍异步，草稿缓存与显式重新加载行为不变。

SettingsNavigationPerformance 记录首次和三次重复切换的同步耗时及总耗时，限制首次同步阶段小于 1.5 秒、重复阶段小于 1 秒，防止多秒阻塞复发。测量使用独立配置，具体结果及边界见开发验证记录；不是对任意设备和云端磁盘延迟的承诺。

## 语言边界

使用 .NET 自带 ResourceManager / .resx，不增加包或 UI 框架。`Strings.resx` 是中文中性资源，`Strings.en-US.resx` 生成英文卫星程序集，安装包必须包含 `en-US/HarborBackup.Tray.resources.dll`。

`Localization/UiText` 负责显示文本和控件更新，控件销毁时取消订阅。页面名称、枚举、JSON 字段和调度判断不依赖显示语言。资源键使用源语言文本，格式参数交给资源格式化；路径、用户项目名、原始输入不参与翻译。只对界面格式化使用指定 CultureInfo，不改变进程区域设置或持久化协议。

语言覆盖主窗口五页、托盘菜单与通知、项目编辑、预览、帮助以及应用自身的确认文案。Windows 文件选择器和原生 MessageBox 按钮由系统语言决定。CLI、原始日志、枚举诊断代码和第三方/系统异常保持原文，便于排查；本次不引入诊断代码协议迁移。

`DesktopPreferences.Language` 存储 `zh-CN` / `en-US`，仍采用本机 ui.json schemaVersion 1 的可选字段扩展。旧文件缺少字段或未知语言时显示中文，已有窗口与目录偏好保留；不写共享 system-config.json 或 bakup-config.json，不影响另一台电脑。

## 验证

资源测试检查两种语言键集合、格式参数数量以及英文卫星程序集可用。偏好测试覆盖旧文件默认语言和保存后的重新读取。真实 WinForms 控件测试在同一窗口改动草稿后往返切换语言，检查草稿、数值、持久化、配置文件未改写，以及两种语言常规/最小窗口的标题和设置行边界。

通过 HARBORBACKUP_SCREENSHOT_DIR 输出双语页面、设置顶部/底部、帮助、编辑器和预览的控件渲染图；HARBORBACKUP_UI_DPI=96 提供单独的 96 DPI 检查。实际测试数量、发布安装信息及尚未完成的系统交互验证见 [开发验证记录](development-validation.md)。
