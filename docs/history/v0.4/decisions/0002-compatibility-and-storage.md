# ADR-0002：磁盘协议兼容与 JSON 存储

- 日期：2026-10-27
- 状态：JSON 与旧状态兼容已实现；新事务由 [ADR-0004](0004-transaction-v2.md) 补充

## 背景

现有工具已有设备隔离状态、共同基线、事务及归档元数据，存放于 OneDrive 同步目录。更名和语言迁移不能丢失恢复关联。

## 决定

继续使用 JSON，不引入同步目录内的 SQLite。保留旧设备/任务身份、配置文件名和兼容标识。领域模型与存储 DTO 分开，先读取验证，再建立受控写入。未知格式拒绝写入，版本迁移显式执行并保留原件。

缓存、共同基线和运行摘要分别建模；本机暂停使用设备目录内新增 control.json。同步目录内每台设备仅写自身状态。

## 替代与代价

数据库可改善查询与事务体验，但引入同步兼容问题和额外迁移。JSON 易检查、兼容成本低，但多文件不具备整体事务；必须保留独立恢复记录，避免频繁全量写入。

## 验证

固定身份向量、旧格式往返读写、未知 schema 拒写、损坏/外部修改保护、状态提交前后崩溃恢复。不得因品牌更名改变 AutoBackup/v1 输入。
