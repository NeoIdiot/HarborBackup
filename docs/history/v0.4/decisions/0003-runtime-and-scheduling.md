# ADR-0003：运行入口与调度

- 日期：2026-10-27
- 状态：已实现，隔离测试通过，生产切换待验收

## 背景

需要轻量常驻托盘及手动 CLI，又要在迁移期避免与旧周期任务同时写入。

## 决定

正式切换后托盘负责调度，当前用户登录启动一次。采用独立托盘实例锁和任务运行锁；CLI 直接使用同一核心与运行锁，不先建设 IPC。自动触发忙碌时跳过，不积压。暂停不终止当前文件事务，退出在安全边界停止。

周期继承现有配置。切换前保留旧任务；切换时停用旧触发、等待旧运行完成、检查事务和迁移，再启用新入口。兼容期维持旧会话范围互斥，跨会话增强另行设计。

2026-10-28 实现补充：当前用户 HKCU Run 注册单个 HarborBackup 登录命令，只有菜单操作才写入；启动不改计划任务。调度使用单调时钟，暂停存入本机 control v1，CLI 改变暂停后托盘在空闲轮询读取。详见 [托盘说明](../tray.md)。

## 替代与代价

系统服务适用于无人登录备份，但超出当前产品范围。继续由周期计划任务启动全部工作也可行，但与常驻托盘调度形成两个所有者。采用托盘后，退出/注销意味着自动备份停止，必须明确展示。

## 验证

多入口竞争、重复启动、忙碌触发、暂停、休眠恢复、退出与系统强制结束；恢复协议不能依赖关机一定给予充足等待时间。
