# ADR-0001：平台与模块边界

- 日期：2026-10-27
- 状态：已实现四工程与共享核心，2026-10-28 更新

## 背景

产品仅面向 Windows，需要轻量托盘、现有 Windows 文件能力和可独立验证的备份逻辑。

## 决定

使用 C#/.NET 10 LTS，WinForms 实现托盘。保留 Core、Windows、CLI、Tray 四个产品工程。Core 定义领域和用例，Windows 实现外部能力，两个宿主共享核心并在启动入口组装依赖。

## 替代与代价

继续扩展 PowerShell 会增加长期类型、状态和界面维护成本；WPF/跨平台 UI 对当前界面需求没有必要收益；服务加客户端会增加部署和 IPC 复杂度。四工程仍有组装成本，应避免进一步无需求拆层。

## 验证

Core 可不依赖 Windows 运行纯决策测试；宿主行为对同一用例一致；托盘无启动主窗口和控制台闪烁，耗时操作不阻塞 UI。
