# ADR-0006：自包含 Windows 安装包

日期：2026-10-28。状态：实现；实际验收和签名限制见开发验证记录。本记录替代初版默认依赖系统运行时的发行选择，不改变备份协议或生产切换要求。

用户选择安装后直接运行，并要求先实测体积、安装占用和托盘内存。采用 Inno Setup 7.1.0、Windows x64、.NET 10.0.14 自包含目录发布；WinForms 不启用裁剪。CLI 也引用 Desktop Forms 框架以获得同样的框架替代程序集，避免两个自包含发布的同名 DLL 不一致；因此依赖运行时的 CLI 诊断版也需要 Desktop Runtime。

安装目录与工作区分离。显式路径不变，installed-mode.json 只选择安装版默认路径。进程与安装器在相同互斥下创建生命周期标记，避免升级期间新启动；忙碌时要求安全退出，不使用强杀、自动重启替换或清除事务来完成安装。卸载保留用户数据。

代价是约一份完整未裁剪运行时的磁盘占用，运行时补丁由应用发行维护。单文件不带来必然更小的体积，故交给安装器统一压缩。共享系统运行时保留为诊断选项；MSIX、MSI、Native AOT 和自动更新不在本轮范围。

构建需锁定依赖和版本、校验重复依赖/清单、保留许可证。开发安装包未签名，受签名策略约束的环境不视为通过运行验收；不绕过系统应用控制。

详细方案见 [安装包开发方案](../installer-plan.md)，用户说明见 [安装与使用](../installation.md)。
