# 产品需求与安全不变量

## 第一版范围

手动启动打开主窗口，登录启动进入托盘，不显示黑色控制台。主窗口支持项目配置、排除规则、调度/核查设置、备份、预览、指定项目取回、运行记录和问题详情；关闭窗口隐藏到托盘，显式退出才停止后台调度。详见 [主窗口说明](main-window.md)。

托盘和 CLI 共用引擎。配置使用 JSON，沿用全局与项目排除规则的并集；目标直接使用 OneDrive 根下的 destination。普通轮次复用元数据缓存，每个文件按原核查时间判断是否到期，当前间隔为七天。

第一版不做自动合并、删除传播、重命名识别、OneDrive 云端 API、Windows 服务、自动更新和 Native AOT。配置编辑仅开放已实现能力，保留高级字段，不直接编辑缓存/事务。

## 不变量

| 编号 | 约束 |
| --- | --- |
| INV-01 | Backup 不写源；Pull 不写目标，也不顺便上传 |
| INV-02 | 覆盖不同内容前保护并核验旧版本；不能删除原文件作为降级替换 |
| INV-03 | 未完成实际内容核验，不推进共同基线 |
| INV-04 | 不可读取、被占用、下载失败与不存在严格区分 |
| INV-05 | 不传播删除；同时间不同内容保存双方并待处理 |
| INV-06 | 写入前版本或路径变化必须重新判断或延期 |
| INV-07 | 恢复与重试幂等；遇到未知版本或现场内容保留证据 |
| INV-08 | 本机写入互斥；不宣称跨设备串行化 |
| INV-09 | 预览不写业务文件、缓存、事务，不执行恢复或维护 |
| INV-10 | 本地完成与云端上传状态分开，不推断云端已经收到数据 |
| INV-11 | 未解决冲突及恢复引用不得被普通归档清理删除 |
| INV-12 | 用户明确选择项目并执行 Pull，且源项目根已存在并验证通过 |

预览允许输出到控制台；若后续允许写诊断报告，必须显式标注。读取仅联机内容可能下载文件，不承诺预览零网络或零空间影响。

## 状态展示

运行阶段、运行结果、待处理问题分别建模，不用单一成功布尔值代替。

- 阶段：空闲、恢复检查、扫描、核查、复制、维护、正在停止。
- 结果：完成、部分完成、失败、取消。
- 问题：未解决冲突、待取回、待上传、延期、释放空间待重试。
- 时间：最近运行结束、最近无待处理问题完成、下次自动触发；暂停时显示已暂停。

完整核查菜单必须区分“仅核查”和“核查并备份”。旧 FullCheck 会与备份结合，新增只核查入口需明确说明。通知优先用于冲突、失败和恢复问题，不为每轮正常完成弹窗。

## 保障边界

本工具提供单文件保护与恢复，不提供整个项目的时间点快照或跨设备事务。数据库、虚拟机镜像等应用一致性不在第一版保证范围内。

元数据缓存可能暂时漏掉大小和修改时间完全不变的内容修改；定期完整哈希补查。OneDrive 本地视图不能证明其他设备已上传全部变更。

自动归档清理只能使用本机已可见的保护信息，无法保护尚未同步到本机的远端事务。多设备交接仍需先等待同步、预览、再明确取回。
