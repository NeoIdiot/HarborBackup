# 发布、迁移与回退

## 发布方案

默认发行已改为 Windows x64 自包含安装包，内置 .NET 10 Desktop 运行环境，不需要用户安装 SDK 或系统运行时。保留 WinForms，不启用裁剪、单文件或 Native AOT。完整设计见 [安装包方案](installer-plan.md)，用户操作见 [安装说明](installation.md)。

当前 `scripts/deployment/Publish.ps1 -IsolatedProfile` 生成 artifacts/publish/HarborBackup-<版本>-<时间>-<标识>/app 和逐文件清单。两个入口使用一致的 Desktop 框架依赖，合并并校验同名文件；用户包包含运行时许可和简明说明，不包含 PDB、开发资料或真实配置。Build-Installer.ps1 将 app 目录压缩为 Setup.exe；-FrameworkDependent 仅为诊断替代，不用于默认安装包。工具、运行时版本固定在 packaging/windows/release.json。

产物放在 artifacts，程序与运行数据分开。保留旧程序版本，更新时先安全退出；不直接覆盖正在运行的 EXE/DLL。第一版不做自动更新、安装服务或 Native AOT。

安装器和两个入口通过进程生命周期标记协调：运行中拒绝升级/卸载，维护期间拒绝新启动；不强杀应用。正式公开发行需要发行者签名，当前未签名开发包可能被应用控制策略拒绝，实际限制以验证记录为准。不能将编译成功等同于目标机可以运行。

文件路径相对明确的应用/配置根解析。目录移动后，Windows 登录启动注册中的绝对路径仍需重新登记，不能宣称外部注册项自动迁移。

## 开发与验证期间

早期开发保留旧 PowerShell 周期任务。2026-10-28 按用户要求已停用 OneDrive-Project-Backup，定义保存在忽略的 artifacts/migration/stop-legacy-20261028-123604，确认当时无旧同步进程。此操作不等于完成新程序的生产迁移。C# 默认在隔离临时目录验证，真实配置只读预览应持有兼容锁或在明确稳定的读取条件下执行，不能和旧写入竞争生成误导性结果。

不能把父目录真实配置直接复制为可运行测试配置；生产 source/destination、state 和归档路径必须显式映射并审核。示例环境变量未配置时失败，不回退到真实桌面。

## 切换前检查

- 兼容测试、事务故障测试、托盘/CLI 互斥通过。
- 生成迁移报告：身份一致性、任务映射、格式版本、未完成事务、实际数据根、配置差异。
- 真实配置预览通过，阻塞项已处理。
- 记录旧任务定义及本机运行入口，确认回退程序可用。
- 明确旧版本是否能读取新版本将写出的状态；否则准备显式反向迁移或重新核查方案。

## 正式切换顺序

1. 停用旧周期触发器，不直接杀死正在执行的文件事务。
2. 等待旧运行结束，取得兼容运行锁。
3. 检查未完成事务，备份配置和状态快照，保留对应修订与时间。
4. 如需格式迁移，校验输入并生成新文件，验证后提交；失败保留原件。
5. 运行一次受控备份，确认文件、归档、状态和日志结果。
6. 注册本机 C# 登录启动并启用托盘调度；周期继承配置。
7. 确认旧周期入口已停用，新入口只有一个。记录切换结果和恢复方式。

登录启动使用当前用户 HKCU Run 的 HarborBackup 项，由主窗口设置页显式切换，命令带 --background；不创建启动快捷方式或新计划任务。程序与配置移动后重新登记。构建、发布和初次启动不会写注册表或停用旧任务。

## 回退顺序

1. 停止 C# 新触发，安全结束当前任务并取得运行锁。
2. 检查新程序未完成事务，保留现场与日志。
3. 若磁盘协议仍与旧版兼容，经验证后恢复旧入口。
4. 若协议不兼容，执行已验证迁移；无法可靠迁移时停止写入并保留证据，先核查实际文件。
5. 只恢复一个自动入口，完成受控验证后恢复周期运行。

回退程序不等于回退业务文件。不能盲目还原切换前 files.json，因为实际文件可能已经更新；也不能为了恢复旧程序批量删除新事务、归档或目标内容。

当前 files v1 / status v2 的新输出已通过旧读取器检查；新事务为 v2，旧程序会拒绝。存在 v2 未完成事务时，必须用 C# 恢复/处理现场，不可直接回退。控制文件为本机新增 v1 协议。迁移报告与切换/回退自动化仍未交付，生产入口未切换。

## 运行说明应包含

暂停仅暂停后续自动运行；退出托盘即停止本机自动备份；注销/关机可能迫使进程中断，下次启动恢复；OneDrive 同步完成仍需用户通过 OneDrive 确认。空间释放失败单独重试，不改写已完成备份的事实。
