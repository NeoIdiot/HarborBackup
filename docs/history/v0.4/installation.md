# HarborBackup 安装与使用

默认发行 Windows x64 自包含安装包。无需安装 .NET SDK 或 Desktop Runtime，安装后从开始菜单打开 HarborBackup。安装程序不运行 PowerShell，不联网下载运行时。

程序安装在 `%LOCALAPPDATA%\Programs\HarborBackup`，仅当前用户可见。安装版默认配置在 `%LOCALAPPDATA%\HarborBackup\workspace`，首次在主窗口“设置”选择本机 OneDrive 根，再添加项目。初次没有项目，不会执行备份；保存项目后按界面显示的时间自动调度。登录启动默认不登记，可在设置中显式启用。

程序目录中的 installed-mode.json 标记安装模式。CLI 与主窗口使用同一默认配置位置；显式 --config、--system-config 参数优先。CLI 的云根仍通过 --onedrive-root 或 OneDrive 环境变量指定，不读取桌面 UI 偏好。

接入旧数据时，使用启动参数指向原配置位置，先预览并执行既有迁移检查。不搬动配置后重新解释相对路径，不自动停用旧计划任务。移除 installed-mode.json 的独立目录副本使用便携默认路径；不建议修改已安装目录来切换模式。

升级前从托盘选择“退出并停止本机自动备份”，等待安全结束，并结束 CLI 操作，然后运行新安装包。安装和卸载会拒绝在本版本程序运行时替换文件，期间也拒绝新的程序入口。旧的开发版本没有安装协调协议，必须先手动退出。禁止绕过提示强行覆盖占用文件。升级保留原配置和登录启动选择，拒绝降级；第一版不提供自动更新或断电级安装回滚。

可从 Windows“已安装的应用”卸载。卸载仅删除安装器登记的程序文件、快捷方式，以及指向本安装目录的 HarborBackup 登录启动项。配置、状态、日志、冲突、归档、源文件和备份目标均保留；不删除系统运行时，也不处理旧任务。

主窗口包含概览、备份项目、运行记录、待处理问题、设置。关闭窗口仍在托盘运行，退出才停止自动备份。取回更新必须选定项目；本地复制完成不代表 OneDrive 云端上传完成。

设置页的“保存备份设置”“重新加载”固定在窗口右下角，不随设置内容滚动。后台每五秒重新读取配置不会显示备份进度动画或改变设置页高度，实际执行备份/预览时才显示进度。

在“设置 → 界面 → 语言”（Settings → Appearance → Language）选择简体中文或 English，立即生效并记住本机偏好，无需重启。未保存的设置草稿保留。设置项解释、排除规则和操作说明集中在设置内容最后的帮助按钮，中文显示“帮助”，英文显示“Help”；项目编辑窗口也提供帮助入口。系统文件选择器和系统消息框按钮沿用 Windows 的语言，底层诊断日志保留原文。

本发行版未裁剪 WinForms 框架，保留运行时所需文件和第三方许可。私有 .NET 运行时安全更新需要随 HarborBackup 新版本安装包发布。未签名的开发构建与正式签名发行分开标记；不要求关闭 Windows 安全功能。
