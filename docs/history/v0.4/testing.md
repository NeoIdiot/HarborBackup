# 测试与验收策略

## 分层与工具

| 测试组 | 内容 | 执行环境 |
| --- | --- | --- |
| Core.Tests | 冲突决策、不变量、用例、结果汇总、可控时间 | 内存模型，无真实磁盘依赖 |
| Windows.Tests | 路径、哈希、复制、持久化、恢复、锁 | Windows 独立临时目录 |
| Compatibility.Tests | 旧格式读写、身份、指纹、排除、旧新结果差异 | 合成夹具、隔离 PowerShell 参考执行 |
| 人工系统验收 | 托盘响应、无控制台、关机、占位文件、两设备交接 | 专用测试目录和测试设备 |

桌面语言与布局覆盖中英文资源一致性、旧偏好读取、即时切换保留草稿、设置行及顶部按钮边界。可用 `HARBORBACKUP_SCREENSHOT_DIR` 输出实际控件渲染图，分别以默认 DPI 和 `HARBORBACKUP_UI_DPI=96` 运行 HostTests；渲染不能替代跨屏和无障碍系统验收。参见 [语言与帮助设计](ui-language-and-help.md)。

已使用 MSTest 4.0.1 创建三个测试工程，SDK 基线为 10.0.100。实际运行结果、环境限制见 [验证记录](development-validation.md)。纯模拟文件系统不能证明 Windows 文件替换和共享模式正确。

## 必测场景

| 场景 | 关键断言 | 关联要求 |
| --- | --- | --- |
| 内容相同、时间不同 | 不因时间差重复覆盖 | COMP-08 |
| 时间相同、内容不同 | 两端保留，待处理 | INV-05 |

| 暂停、退出、休眠、时钟变化 | 不堆积任务，安全停止 | 产品生命周期 |
| 配置修改后恢复 | 不把旧事务应用到新映射 | INV-06、INV-07 |

## 差异验证

冻结合成数据、时间、设备输入和配置，在相同初始数据的两个独立副本运行旧参考与新引擎。比较动作、原因分类、归档类别、相对路径、哈希、基线变化及退出码；运行 ID、真实耗时等非确定字段先规范化。

参考执行不得装卸计划任务或请求真实 OneDrive 空间释放；必要时使用明确的适配替身。旧缺陷必须形成已记录的期望差异，不能把所有差异都忽略。

## 测试夹具

fixtures 仅存合成/脱敏的小数据和预期输出。每组样例记录协议版本、输入来源、预期动作和覆盖的 INV/COMP 编号。大文件用运行时生成方式创建；不要提交真实文档、设备状态或业务日志。

测试使用唯一临时目录，不使用仓库父目录的生产配置。清理前验证绝对路径位于该测试目录；失败时可保留诊断证据并输出位置。

## 性能报告

固定机器、文件数量、大小分布、缓存状态和占位情况；区分首次备份、缓存轮、完整核查、只读预览。

记录发布体积、托盘空闲和备份峰值内存、扫描文件数、哈希字节数、复制字节数、缓存命中数及耗时。未测得时不承诺固定体积或内存目标。按需下载流量与本地复制耗时分开解释。

## 验证记录格式

每次记录提交/源码版本、环境、数据集、执行命令、通过/失败数量、未执行项和证据位置。历史 PowerShell 测试通过不代表 C# 兼容已通过。

除构建和行为测试外，仍检查文档链接、JSON 语法、Git 忽略、旧源码摘要及无生产目录副作用。结构样例本身不代表恢复或维护通过，实际写入与恢复结果以验证记录为准。

新增 Test-WriteCycle.ps1 验证 CLI 完整循环及旧读取器；TransactionTests 覆盖中断、竞争窗口、归档/状态失败和恢复；HostTests 在独立 STA 消息循环验证后台启动无窗口、关闭主窗口仍运行和退出释放图标，不修改登录注册。SchedulingTests 使用可控单调时钟验证暂停、忙碌、休眠式时间跃迁和安全停止。

主窗口增量：ConfigurationEditorTests 覆盖配置保护、草稿与初始化；HostTests 覆盖两种启动方式、控件保存、页面导航、隐藏和实例激活。可设置 HARBORBACKUP_SCREENSHOT_DIR 导出六类布局图片。测试将本机偏好路径注入独立临时目录，禁止借 UI 验证写真实登录注册。互斥跨线程断言使用独立 Thread，避免等待 Task 时的内联执行使测试落在锁持有线程。

安装增量：InstallationTests 验证安装/便携默认路径、显式覆盖、无读取副作用和维护标记。Test-Installer.ps1 仅运行隔离变体，-FilesOnly 明确跳过运行验收；Measure-InstalledTray.ps1 不用测试宿主冒充真实托盘进程。受应用控制阻止时记录系统事件和失败，不能关闭安全策略或将未测得内存记作 0。
