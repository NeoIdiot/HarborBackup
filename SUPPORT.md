# 使用与问题反馈 / Help and feedback

先查看 [README](README.md)、[OneDrive 账户使用说明](docs/user-guide/onedrive-account.zh-CN.md) 和 [验证记录](docs/development/validation-index.md)。开发环境与测试入口见 [CONTRIBUTING.md](CONTRIBUTING.md) 及 [验证规范](docs/development/verification.md)。

在仓库的 Issues 页面选择问题报告或优化建议表单。提供应用版本、Windows 版本、最小复现和预期/实际行为。请用虚构路径和合成文件；只分享必要的脱敏错误片段或截图，检查截图中的文件名、路径和账户信息。

不要公开整个 data、配置或日志目录、令牌、授权缓存、预授权 URL 或真实业务文件。疑似安全漏洞按 [SECURITY.md](SECURITY.md) 私密报告。项目没有承诺答复时限；当前限制和未测项以版本验证记录为准。

Start with the [README](README.md), [OneDrive account guide](docs/user-guide/onedrive-account.en-US.md), and [validation records](docs/development/validation-index.md). Development instructions are in [CONTRIBUTING.md](CONTRIBUTING.md) and the [verification guide](docs/development/verification.md).

Use the bug or feature form on this repository's Issues page. Include the app and Windows versions, minimal steps, and expected/actual behavior. Use fictional paths and synthetic files. Share only essential redacted excerpts or screenshots, checking filenames, paths, and account details before posting.

Do not publish a whole data/config/log directory, tokens, credential caches, preauthenticated URLs, or real business files. Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. No response deadline is promised; release validation records describe current limits and untested areas.
